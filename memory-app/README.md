# Bob – אפליקציית זיכרונות (Memory App)

אפליקציית React ליצירת "זיכרונות" אישיים — סיסמאות, שמות משתמש, מספרי טלפון, קודים, תעודות זהות ועוד — עם חיפוש לפי נושא, חיפוש כללי, נעילת אפליקציה בקוד בן 4 ספרות, ומצב תצוגה בהיר/כהה. הנתונים נשמרים אוטומטית ב-localStorage של הדפדפן, במכשיר בלבד.

⚠️ **גרסת בטא / דמו ויזואלי בלבד.** המידע נשמר בטקסט גלוי ב-localStorage וללא הצפנה — לא מתאים לשמירת סיסמאות אמיתיות בסביבת פרודקשן. לפני שימוש עם מידע רגיש אמיתי יש להוסיף שכבת אבטחה (הצפנה, אימות מאובטח וכו') דרך גורם מוסמך.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
```

## מה יש באפליקציה

- **מסך הבית** — הוספת זיכרון חדש: קודם נושא (למשל "סיסמה לאינסטגרם"), ואז התוכן (למשל הסיסמה עצמה). כולל כפתור הקלטה קולית (Web Speech API, אם נתמך בדפדפן).
- **תפריט (☰)** — הוספה מהירה, חיפוש לפי נושא, חיפוש מידע כללי, וכפתור "פתח טבלת אקסל עסקית" (בקרוב), ורשימת "אחרונים שנשמרו".
- **הגדרות (⚙)** — מעבר בין מצב כהה לבהיר, יצירת/שינוי/ביטול קוד נעילה בן 4 ספרות לאפליקציה, ומילוי פרטי זהות אישיים (שם, טלפון, כתובת — הכל אופציונלי).
